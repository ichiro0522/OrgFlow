# OrgFlow プロジェクト概要

- 設計ID: SYS-OV-001
- 対象: 中小企業向け社内業務管理プラットフォーム
- 目的: 社員・組織を共通基盤として報告、承認、申請、通知、ファイル、監査を一元管理する。

## 想定規模
従業員10～200名程度、業種を限定しない。

## 開発フェーズ
基本設計 → 詳細設計 → 実装 → 単体テスト → 結合テスト → 総合テスト → リリース・運用保守

要件定義書は作成しない。

## 基本方針
- モジュラモノリス
- PHP/Laravel、Vue.js、PostgreSQL、REST API
- DB主キーUUID原則
- クラウド・オンプレミス対応
- 将来モジュール、契約プラン、AIを疎結合に追加可能

## 未決定事項
- Laravel、PHP、Vue、PostgreSQLの具体バージョン
- 認証方式、テナント識別方式、個人情報保持方針
