# 開発方針

- 設計ID: SYS-POL-001

## 原則

1. 基本設計から開始し、要件定義フェーズを設けない。
2. 詳細設計前に基本設計・横断設計を確認する。
3. 設計、実装、テスト間で設計IDをトレースする。
4. モジュール間依存は公開インターフェースまたはドメインイベント経由とする。
5. 不確定事項は推測で確定せず、未決定として記録する。
6. 既存機能・既存設計への影響を確認し、変更時に関連文書を更新する。

## 初期実装対象

Employee、Organization、Report、Workflowを優先候補とし、Coreから共通基盤を提供する。休暇申請等の将来機能は初期実装対象外とする。
